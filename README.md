# tesi-doc

Eine einfache Hello-World-Web-Applikation zum Testen von GitHub Pages.

## Lokal ansehen

`index.html` einfach im Browser öffnen.

## Auf GitHub Pages veröffentlichen

1. Im Repository auf **Settings → Pages** gehen.
2. Unter **Build and deployment** als Source **Deploy from a branch** wählen.
3. Den Branch (z. B. `main` oder `claude/hello-world-git-pages-6cqwzn`) und den Ordner `/ (root)` auswählen und speichern.
4. Nach ein bis zwei Minuten ist die Seite unter `https://trmntn.github.io/tesi-doc/` erreichbar.
